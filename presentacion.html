La idea

¿Qué es un mod?

Un plugin con funciones que se enganchan a lo que pasa dentro de Claude Code.

Escribes un mensaje
→
Claude usa una herramienta
→
Termina el turno

En cada uno de esos momentos (eventos), tu mod puede mirar, cambiar o bloquear lo que pasa.

Analogía: es como un guardia en una puerta. Cada cosa que pasa por ahí, el guardia la ve y decide si la deja pasar, la cambia o la detiene.

Lo que se puede hacer

Un mod puede…

📊

Barra de estado

Mostrar un texto fijo abajo: $.ui.status()

🔔

Avisos (toast)

Un mensaje que aparece unos segundos: $.ui.toast()

⛔

Bloquear

Impedir que Claude haga algo: { deny }

❓

Preguntarte

Mostrarte opciones y esperar tu respuesta: $.ui.ask()

🧱

Dibujar

Una franja encima del prompt o un panel lateral.

⌨️

Comandos propios

Crear tus propios /comandos.

Anatomía

Un mod son 3 archivos

cronometro/
├── .claude-plugin/
│   └── plugin.json     ← nombre y descripción
└── hooks/
    ├── hooks.json      ← qué archivo cargar
    ├── register.ts     ← el código
    └── register.test.ts ← sus pruebas (opcional)

plugin.json → la "cédula" del mod.

hooks.json → le dice a Claude Code dónde está el código.

register.ts → lo que hace el mod. Aquí está todo lo interesante.

Se escribe en TypeScript. Si dibuja algo en pantalla, usa .tsx.

La fórmula

Todo mod se ve así

export const register: Register = on => {
  on('evento', ($, e, next) => {
    // $    → las herramientas (mostrar avisos, preguntar, guardar datos…)
    // e    → lo que está pasando (el mensaje, el comando, etc.)
    // next → "déjalo seguir"
    return next(e)
  })
}

Regla de oro: si no haces nada especial, termina con return next(e) para que todo siga normal.

Decidir

Tres maneras de responder

✅

Dejar pasar

return next(e)

Todo sigue igual.

✏️

Cambiar

return next({ ...e,
  command: nuevo })

Sigue, pero con algo distinto.

⛔

Bloquear

return {
  deny: 'Motivo' }

Se detiene y Claude lee el motivo.

Ejemplo 1 · crear desde cero

Mod cronometro: el plan

Queremos saber cuánto tardó Claude y cuántas herramientas usó en cada respuesta.

  1. Al enviar un mensaje (prompt.submit) → pongo el contador en 0.
  2. Cada vez que Claude usa una herramienta (tool.call) → sumo 1 y lo muestro abajo.
  3. Al terminar (turn.complete) → muestro el resumen y un aviso.
Probar

Tres maneras de probarlo

ManeraComandoPara qué
1. Revisarclaude plugin validate ./plugins/cronometroQue no tenga errores de forma
2. Pruebas automáticasclaude plugin test ./plugins/cronometroQue haga lo que debe, sin abrir Claude
3. Usarlo de verdadclaude --plugin-dir ./plugins/cronometroAbre Claude Code con el mod cargado (sin instalarlo)

Con la opción 3, cada vez que guardas el archivo, el mod se recarga solo. Edita, guarda y vuelve a probar.

Guardar datos

¿Dónde guarda cosas un mod?

🧠

Variable normal

let tools = 0
Se pierde al recargar el mod. Bien para contadores rápidos.

📋

$.state

Vive mientras dure la sesión. Si cambia, la pantalla se redibuja sola. (aprobar-dependencias)

💾

$.store

Se guarda en disco y sobrevive entre sesiones. (mis-notas)

Compartir

De carpeta a "tienda" (marketplace)

Un solo archivo convierte tu repositorio en una tienda de mods:

.claude-plugin/marketplace.json

{
  "name": "claude-mods",
  "owner": { "name": "alexyslozada" },
  "plugins": [
    {
      "name": "cronometro",
      "source": "./plugins/cronometro",
      "description": "Mide cada turno"
    }
  ]
}
  1. Crea el archivo en la raíz del repo.
  2. Añade una entrada por cada mod.
  3. Sube el repo a GitHub (git push).

Listo: cualquiera puede instalar tus mods con una línea.

Instalar

Instalar un mod

Dentro de Claude Code, en la terminal:

/plugin install cronometro --marketplace alexyslozada/claude-mods
  1. Pregunta si añade la tienda → responde y.
  2. Elige el alcance: user (todas tus sesiones), project (este proyecto, compartido) o local (este proyecto, solo tú).
  3. Sale "Installed cronometro. Plugin is now active." → ya funciona, sin reiniciar.

Para los demás, cambia el nombre: viernes-sin-deploy, aprobar-dependencias, mis-notas.

Ojo

Un mod tiene tus mismos permisos

Corre en tu máquina, con los mismos permisos que Claude Code.

  • Instala solo mods de gente en la que confías.
  • Lee el código antes (son archivos cortos).
  • Si un mod "guardián" falla, decide qué hacer con .catch(): dejar pasar o bloquear.
